# CAN フレーム再生用データ (SWR-101)

ベンチテスト（`IT-*` / `QT-*`）で実車の代わりに CAN フレームを送出するためのシーケンス。
USB-CAN アダプタまたは別の ESP32 + CAN Unit から送出する。

## 形式

```
# time_ms, can_id(hex), dlc, d0, d1, d2, d3, d4, d5, d6, d7
0,207,8,10,27,00,00,00,00,00,00
0,209,8,A9,00,00,00,00,00,00,00
50,207,8,34,21,00,00,00,00,00,00
50,209,8,B4,00,00,00,00,00,00,00
```

- `time_ms` は先頭行からの相対時刻。同じ時刻の行は同一周期で送る。
- `#` で始まる行はコメント。
- 値は 16 進、リトルエンディアン（`DOC-13 §1`）。

## 用意すべきシーケンス

| ファイル | 用途 | 対応テスト |
|---|---|---|
| `idle.csv` | アイドル相当（λ 1.00、EGT 500 degC）を 20 Hz で連続送出 | `IT-01` |
| `sweep.csv` | λ を 0.68 → 1.36 → 0.68 でスイープ | `QT-02`, `QT-03` |
| `egt_danger.csv` | EGT を 920 degC 超まで上げる | `QT-05` |
| `dropout.csv` | 5 秒送出 → 5 秒停止 → 再開 | `IT-02` |
| `burst.csv` | 全 12 フレームを 5 ms 周期で送出 | `IT-03` |
| `invalid.csv` | λ=0 / EGT=0 / DLC 不足フレームを混在 | `IT-02`, `UT-09` の実機確認 |

（P2 のブリングアップ時に作成する）
