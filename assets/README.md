# assets

| ファイル | 用途 | 生成方法 |
|---|---|---|
| `logo_src.png` | オープニング画面のロゴ元画像（240×240 以内） | 手動で用意（`OPN-05`） |
| `logo.c` | LVGL 用の C 配列に変換したもの | `tools/make_logo.py`（P4 で作成） |
| `fonts/*.c` | 数字専用フォント（72px / 32px, Bold） | LVGL Font Converter（`DOC-23 §9`） |

元画像（`*_src.png`）と生成物（`*.c`）の**両方を git で管理する**（`DOC-40 §1`）。
生成物だけだと差し替えができず、元画像だけだとビルド環境にフォント変換ツールが必要になるため。
