# 6. 起動ロゴを変える

[← 5. 表示を変える](05_customize.md) ｜ [目次](README.md) ｜ 次: [7. 最新版に更新 →](07_update.md)

電源を入れた直後の約 3 秒に出るロゴを、自分の画像にできます。

## 6.1 画像を用意する

| 項目 | おすすめ |
|---|---|
| 形式 | PNG（JPEG なども Claude が変換します） |
| 形 | **横長**。画面の中央の 408 × 174 の枠に、縦横比を保って縮小されます |
| 背景 | **黒** か **透明**。画面の背景が黒なので、白い背景のままだと白い四角が浮いて見えます |
| 白地のロゴしかない | 白い背景に黒（と 1 色）の文字のロゴなら、黒地に白抜きへ自動で反転できます |
| 余白 | 周りの余白は自動で切り取られます |

## 6.2 Claude Code に頼む

```text
起動ロゴをこの画像にして C:\Users\あなたの名前\Pictures\mylogo.png
```

Claude が次のことを行います。

1. 画像を `user/logo.png` にコピーする（許可を求められます）
2. 画像を見て、そのまま使うか反転するかを決めて変換する
3. 丸い画面に置いたときの見え方 `user/logo_preview.png` を作る。**このファイルを開いて確かめてください**
4. よければ書き込む

## 6.3 元のロゴに戻す

```text
起動ロゴを元に戻して
```

`user/logo.cpp` と `user/logo.h` が削除され、次の書き込みで作者のロゴに戻ります。

## 6.4 自分で変換する場合

PowerShell で `circle_meter` フォルダから実行します。

```powershell
python tools/make_logo.py --user
```

白地に黒のロゴを反転したいときは `--invert` を付けます。
変換後は Claude Code に「書き込んで」と頼むか、`./tools/flash.ps1` を実行します。
