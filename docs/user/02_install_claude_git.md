# 2. Claude Code と Git を入れる

[← 1. 準備](01_prepare.md) ｜ [目次](README.md) ｜ 次: [3. コードを手に入れる →](03_get_code.md)

ここだけは Claude の助けを借りずに、自分で 2 つのソフトを入れます。

## 2.1 Git for Windows を入れる

**Git** は、プログラムを作者のところから手に入れたり、最新版に更新したりする道具です。
Windows の Claude Code も Git を使って動きます。

1. ブラウザで **git-scm.com** を開き、「Download for Windows」から最新のインストーラをダウンロードします。
2. ダウンロードしたファイルを開き、**最初から最後まで「Next」のまま（既定の設定のまま）** インストールします。

## 2.2 Claude デスクトップアプリを入れる

1. ブラウザで **claude.com/download** を開き、Windows 版をダウンロードしてインストールします。
2. アプリを開いて、Claude のアカウントでサインインします。
3. 画面上部（または左側）の **「Code」** を開きます。ここが **Claude Code** です。
   Claude Code は、あなたの PC のフォルダの中で、ファイルを読んだり、コマンドを実行したりできる Claude です。

> うまく開けないときは、Anthropic の公式ドキュメント（「Claude Code」で検索）の Windows の項を見てください。

## 2.3 Claude Code への話しかけ方

- **普通の日本語で頼めば大丈夫です。** 例: 「環境を作って」「デモを書き込んで」「さっきのエラーは何？」
- 分からないことはそのまま聞いてください。例: 「COM ポートって何？」「今なにをしているの？」
- 一度に一つずつ頼むと確実です。

### 「許可しますか？」と聞かれたら

Claude Code は、ソフトを入れる・ファイルを書き換える・コマンドを実行する前に、**あなたの許可を求めます**。

| 表示の例 | どうするか |
|---|---|
| `python -m platformio run ...`（ビルド・書き込み） | 許可して大丈夫です |
| `winget install ...` / `pip install ...`（ソフトを入れる） | 何を入れるのか説明を読んでから許可します |
| `user/user_config.h` を書き換える | 許可して大丈夫です（あなたの設定ファイルです） |
| `user` フォルダ以外のファイルを書き換える、何かを削除する | **理由を聞いてから** 決めてください。分からなければ「許可しない」で構いません |

迷ったら「許可しない」を選び、「これは何をするの？」と聞けば説明してくれます。
