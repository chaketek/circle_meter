# 4. 書き込みと配線

[← 3. コードを手に入れる](03_get_code.md) ｜ [目次](README.md) ｜ 次: [5. 表示を変える →](05_customize.md)

## 4.1 まずデモで動作確認する（車に繋がない）

本体を PC に繋いだまま（LCD-2.1 は **UART 側の USB-C**、M5Dial は本体の USB-C）、Claude Code に頼みます。

```text
デモを書き込んで
```

M5Dial のときは「M5Dial にデモを書き込んで」のように機種を添えると確実です（Claude が見つけた本体から判断もします）。

書き込みが終わると Claude が起動ログを読み、結果を `OK` / `NG` で知らせます。
画面に **ロゴ（約 3 秒）→ 針と数字が自動で動くメータ** が出れば成功です。
このデモは CAN を使わないので、配線の前に本体と書き込みが正常か確かめられます。

## 4.2 ECU の設定を確かめる（TunerStudio）

メータが受け取るのは、ECU とワイドバンドコントローラ（WBO）が CAN に出しているデータです。
TunerStudio で次を確かめてください。

| 設定 | 値 | 何のため |
|---|---|---|
| `enableVerboseCanTx` | true | 排気温度などを CAN に出す |
| `canWriteEnabled` | true | 同上 |
| `verboseCanBaseAddress` | 0x200（既定） | 違う値にしている場合は [5. 表示を変える](05_customize.md) の「CAN」で合わせる |
| `canBaudRate`（CAN の通信速度） | 500 kbps（既定） | 違う値にしている場合は同じく [5](05_customize.md) で合わせる |
| `rusefiVerbose29b` | false | |
| 排気温度センサ（EGT1） | 設定済みで TunerStudio に値が出る | 排気温度の表示に使う |
| WBO | 動いていて TunerStudio に λ が出る | λ（空燃比）の表示に使う |

> **λ（空燃比）は WBO から、排気温度は ECU から受け取ります。** どちらかが出ていなければ、その表示だけが `--` や `NO WBO DATA` になります。

## 4.3 配線する

車の **CAN_H / CAN_L** と **12V / GND** を Mini CAN の端子台に入れ、Grove ケーブルで本体と繋ぎます。

### LCD-2.1 の場合

Grove ケーブルを本体の 12 ピンのケーブルと繋ぎます。

| Mini CAN 側（Grove の線の色） | 信号 | 本体の 12 ピン | 本体側のケーブルの色 ※ |
|---|---|---|---|
| 黒 | GND | GND | 黒 |
| 赤 | 5V（Mini CAN が作る） | VBus | 赤 |
| 黄 | CAN TX | D+（GPIO20） | 黄 |
| 白 | CAN RX | D−（GPIO19） | **緑** |

※ 本体側のケーブルの色は、作者が使っている個体での色です。**別の個体では色が違うことがあります。**
必ず、本体の 12 ピンの **信号名（GND / VBus / D+ / D−）** で確かめてください。RX は両端で色が違う（白と緑）ので注意します。

### M5Dial の場合

M5Dial は LCD-2.1 と**電源の向きが逆**です。M5Dial に車の 12V を入れ、Mini CAN は M5Dial から 5V をもらいます。

1. 車の **12V / GND** を、**M5Dial の DC 入力（6–36 V の端子）** に入れます。
2. 車の **CAN_H / CAN_L** を Mini CAN の端子台に入れます。**Mini CAN の端子台には 12V を入れません。**
3. Grove ケーブルで Mini CAN と M5Dial の **PORT.A**（横の赤い Grove 端子）を繋ぎます（4 本とも）。

| Grove の線の色 | 信号 | M5Dial PORT.A |
|---|---|---|
| 黒 | GND | GND |
| 赤 | 5V（M5Dial から Mini CAN へ） | 5V |
| 黄 | CAN TX | G13 |
| 白 | CAN RX | G15 |

M5Dial に電源を入れると、Mini CAN の LED も点きます。

> - Mini CAN が作る 5V で M5Dial を動かす方法（LCD-2.1 と同じ向き）では、**M5Dial は動きません**（作者の車で確認）。
> - この配線で車の CAN を受信できることは、作者がまだ車で確かめていません（ベンチでは同じ配線で受信できています）。
> - M5Dial の DC 入力と USB を同時に繋いでよいかは確かめていないので、**PC と繋いで作業するときは DC 入力を外して**ください。

### 配線の注意

- **LCD-2.1: PC と USB で繋いでいる間は、Mini CAN の端子台に車の 12V を入れないでください。** USB から来る 5V とぶつかります。
  車で書き込み・確認をするときは、CAN_H / CAN_L / GND だけを繋ぎ、電源は USB から取ります。
- **LCD-2.1 のネイティブ USB 側の USB-C には何も挿さないでください**（CAN と同じ線を使っています）。
- **終端抵抗**: エンジンを止めた状態で、車の CAN_H と CAN_L の間の抵抗を測ると **約 60 Ω** になるのが正常です。
  メータを繋いだら約 40 Ω になった場合は、Mini CAN 側にも終端抵抗が入っています。通信が不安定になるので外してください。

## 4.4 車両用を書き込む

本体を PC に繋ぎ、車の CAN にも繋いで、**キーを ON** にしてから頼みます。

```text
車両用を書き込んで
```

Claude が書き込んだあと、20 秒ほど起動ログを読んで判定します。

| 判定 | 意味 |
|---|---|
| `OK  CAN 受信: 200 フレーム/秒、λ センサの状態 OK` | 正常です（数字は車によって違います） |
| `NG  CAN を受信できていません（受信エラー ...）` | **通信速度が車と合っていません。** Claude が 500 kbps と 1 Mbps を入れ替えて書き込み直します（`user_config.h` の `USER_CAN_BITRATE_KBPS`） |
| `NG  CAN のフレームが届いていません` | 配線・キー ON・4.2 の ECU の設定を確かめます |

画面は次のように変わります。

| 画面の文字 | 意味 |
|---|---|
| `SENSOR OFF` / `WARMING UP 500°C` | λ センサが温まっていない・温まっている途中（エンジン始動直後は正常） |
| `NO WBO DATA` | ECU のデータは来ているが、WBO のデータが来ていない |
| `NO SIGNAL` | CAN のデータが何も来ていない |
| `--` | その値（λ や排気温度）が来ていない |

確認できたら USB を外し、車の 12V を Mini CAN に入れて取り付けます。
表示を好みに変えたくなったら [5. 表示を変える](05_customize.md) へ。
