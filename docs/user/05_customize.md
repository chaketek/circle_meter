# 5. 表示を変える

[← 4. 書き込みと配線](04_flash_and_wire.md) ｜ [目次](README.md) ｜ 次: [6. ロゴを変える →](06_logo.md)

## 5.1 Claude Code に頼む（おすすめ）

本体を PC に繋いで、変えたいことをそのまま頼みます。Claude が `user/user_config.h` を書き換え、書き込みまで行います。

```text
針の色を空色にして
```

```text
AFR じゃなくて λ で表示して
```

```text
排気温度の警告を 800 度、危険を 880 度にして
```

```text
リングのデザインに切り替えて
```

```text
全部元に戻して
```

書き込んだあと、Claude が起動ログで「反映した項目」を確かめます。最後に画面を自分の目で見て確かめてください。

## 5.2 変えられること

| 種類 | 変えられること | 項目の名前 |
|---|---|---|
| 既定の表示 | AFR（14.7）か λ（1.00）か | `USER_SHOW_AFR` |
| | デザイン: 指針式（針で指す）か リング（外周の帯） | `USER_DIAL_STYLE` |
| | 画面の明るさ（1〜5） | `USER_BRIGHTNESS` |
| | 理論空燃比（E85 など燃料が違うとき） | `USER_STOICH` |
| λ の色の境目 | 青・水色・緑・黄・赤が切り替わる λ の値 | `USER_LAMBDA_*_MAX` |
| 排気温度 | 警告（黄）と危険（赤・外周が点滅）の温度 | `USER_EGT_WARN_C` / `USER_EGT_DANGER_C` |
| 色 | 針・盤面・目盛り・文字・λ ゾーン・警告の色 | `USER_COLOR_*` |
| CAN | 通信速度（250 / 500 / 1000 kbps）・ベース ID | `USER_CAN_BITRATE_KBPS` / `USER_CAN_BASE_ID` |
| 起動ロゴ | 自分の画像 | [6. ロゴを変える](06_logo.md) |

全部の項目と、使える値の範囲は [user/user_config.example.h](../../user/user_config.example.h) に書いてあります。

> **M5Dial の場合**: 表示デザインはリングだけなので `USER_DIAL_STYLE` と、指針式の盤面・針・目盛りの色（`USER_COLOR_DIAL_*` / `USER_COLOR_NEEDLE`）は使われません。
> それ以外の項目（λ ゾーン・排気温度・文字・背景の色、警告温度、AFR / λ、明るさ、CAN）はどちらの機種でも効きます。
> M5Dial は本体のボタンでも AFR / λ を切り替えられます（電源を入れ直すと設定ファイルの値に戻ります）。

> **警告・危険の色は、走行中に目の端で気づけるよう、明るく目立つ色にしてください。**
> 盤面と似た暗い色にすると、排気温度の異常を見落とすおそれがあります。

## 5.3 自分でファイルを書き換える場合

Claude に頼まずに、メモ帳などで直接書き換えることもできます。

1. `circle_meter\user\user_config.h` を開きます（無ければ `user_config.example.h` をコピーして名前を変えます）。
2. 変えたい行の先頭の `// ` を消して、値を書き換えます。

   変更前（作者の既定の表示が使われる）:

   ```c
   // #define USER_COLOR_NEEDLE      0xFF7014  // 針
   ```

   変更後（針が空色になる）:

   ```c
   #define USER_COLOR_NEEDLE      0x00A0FF  // 針
   ```

3. 保存して、Claude Code に「書き込んで」と頼みます。

- 色は `0x` のあとに 6 桁の 16 進数（赤・緑・青の順に 2 桁ずつ）。例: 赤 `0xFF0000`、白 `0xFFFFFF`。
  「カラーコード」で検索すると色見本が見つかります（`#00A0FF` なら `0x00A0FF` と書きます）。
- 範囲外の値を書くと、書き込みの前に **日本語のメッセージで止まります**（例: `USER_BRIGHTNESS は 1〜5 で指定してください`）。
  メータに変な値が入ることはありません。
- 元に戻すときは、行の先頭に `// ` を付け直します。

## 5.4 設定はどこに残るか

設定は PC の `user/user_config.h` にあり、**書き込んだときにメータに入ります**。
メータの画面からは変えられません（タッチでの設定メニューは今後の予定です）。
作者の最新版を取り込んでも `user` フォルダは上書きされないので、設定はそのまま残ります（[7. 最新版に更新](07_update.md)）。
