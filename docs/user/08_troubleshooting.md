# 8. 困ったとき

[← 7. 最新版に更新](07_update.md) ｜ [目次](README.md) ｜ [用語集](glossary.md)

まずは Claude Code に **症状をそのまま** 伝えてください（例: 「書き込みでエラーが出た」「画面に NO SIGNAL と出る」）。
Claude が起動ログを読んで原因を絞り込みます。自分で確かめたいときは下の表を見てください。

## 本体が PC から見えない（COM ポートが見つからない）

| 確かめること | 対処 |
|---|---|
| 挿している口 | 本体の **UART と書かれた USB-C** に挿す（もう一方のネイティブ USB ではない） |
| ケーブル | **データ通信できる** ケーブルに替える。充電専用のケーブルでは見えません |
| USB ハブ | PC の USB に直接挿す |
| ドライバ | それでも見えなければ、本体の USB 変換チップ（CH343）のドライバが必要です。WCH 社の公式サイトから「CH343」のドライバを自分でダウンロードして入れてください |

## 書き込みで止まる

| 表示 | 対処 |
|---|---|
| `static assertion failed: USER_... は ... で指定してください` | `user/user_config.h` の値が範囲外です。メッセージのとおりに直します（Claude に「直して」と頼めます） |
| `Failed to connect` / `Timed out waiting for packet header` | 本体の **BOOT ボタンを押したまま RESET ボタンを押して離し**、BOOT も離してから、もう一度書き込みます |
| `could not open port` / `Access is denied` | 他のソフト（シリアルモニタなど）が本体を使っています。閉じてからやり直します |
| `MSys/Mingw is not supported` | Git Bash から実行しています。Claude に「PowerShell でやって」と頼みます |
| 初回のビルドがとても遅い・途中で止まる | 初回は道具を 1 GB 以上ダウンロードします。ネット接続を確かめて、もう一度「環境を作って」と頼みます |

## 画面の表示がおかしい

| 画面 | 原因と対処 |
|---|---|
| 真っ暗 | 電源（USB または 12V）を確かめる。PC に繋いで「起動ログを見て」と頼む |
| `NO SIGNAL` | CAN のデータが何も来ていません。配線（CAN_H / CAN_L / GND）、キー ON、[4.2 ECU の設定](04_flash_and_wire.md#42-ecu-の設定を確かめるtunerstudio) を確かめます |
| `NO SIGNAL` で、起動ログに `受信エラー rec=128` | **通信速度が車と違います。** 「通信速度を 1000 にして」（または 500）と頼みます |
| `NO WBO DATA` | ECU のデータは来ていますが、WBO のデータが来ていません。WBO が動いているか、同じ CAN に繋がっているか確かめます |
| `SENSOR OFF` / `WARMING UP` | λ センサが温まるのを待っています。エンジン始動直後は正常です |
| `SENSOR FAULT: ...` | λ センサかヒーターの異常です。TunerStudio で WBO の状態を確かめます |
| 排気温度だけ `--` | ECU が排気温度を CAN に出していません（`enableVerboseCanTx`、EGT1 の設定） |
| 設定を変えたのに変わらない | 書き込み直したか確かめます。起動ログの「反映した項目」に出ていなければ、行頭の `// ` が残っています |

## それでも解決しないとき

Claude に「作者に相談したいので、状況をまとめて」と頼むと、起動ログと設定を整理してくれます。
それを作者に送ってください（GitHub の Issue: github.com/chaketek/circle_meter/issues）。
