# 3. コードを手に入れて環境を作る

[← 2. Claude Code と Git](02_install_claude_git.md) ｜ [目次](README.md) ｜ 次: [4. 書き込みと配線 →](04_flash_and_wire.md)

## 3.1 コードを手に入れる（clone）

1. エクスプローラーで、作業用のフォルダを 1 つ作ります（例: `ドキュメント\meter`）。
2. Claude Code で、そのフォルダを開きます。
3. 次の文をそのまま Claude Code に送ります。

   ```text
   https://github.com/chaketek/circle_meter をこのフォルダに clone してください
   ```

   `circle_meter` というフォルダができ、メータのプログラム一式が入ります。この操作を **clone（クローン）** と言います。

4. Claude Code で、**できた `circle_meter` フォルダを開き直します**（新しい会話として開きます）。
   このフォルダで開くと、メータ用の手順（Skill）を Claude が使えるようになります。

## 3.2 環境を作ってもらう

`circle_meter` フォルダで開いた Claude Code に、次のように頼みます。

```text
環境を作って
```

Claude が次のことを順に行います。途中で何度か「許可しますか？」と聞かれます（[2.3](02_install_claude_git.md#許可しますかと聞かれたら)）。

| 順番 | 内容 | あなたがすること |
|---|---|---|
| 1 | Git・Python・PlatformIO（書き込みの道具）があるか調べる | 待つ |
| 2 | 足りないものを入れる | 許可する。Python を入れた後は **Claude を閉じて開き直し**、「続きをやって」と送る |
| 3 | あなた用の設定ファイル `user/user_config.h` を作る | 待つ |
| 4 | 初回のビルド（道具のダウンロードを含む） | **10〜20 分**待つ。2 回目からは 1〜2 分です |
| 5 | 本体が PC から見えるか確かめる | 本体を PC と繋ぐ（LCD-2.1 は **UART と書かれた USB-C**、M5Dial は本体の USB-C） |

> **LCD-2.1 の USB-C は 2 つあります。必ず「UART」と書かれた方に挿してください。**
> もう一方（ネイティブ USB）は CAN の配線と同じ線を使っているので、挿すと CAN が動かなくなります。
> M5Dial は USB-C が 1 つだけなので、そこに挿します。

「環境ができました」と言われたら、[4. 書き込みと配線](04_flash_and_wire.md) へ進みます。
