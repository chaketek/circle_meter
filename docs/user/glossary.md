# 用語集

[← 目次](README.md)

| 言葉 | 意味 |
|---|---|
| **Claude Code** | PC のフォルダの中でファイルを読み書きしたり、コマンドを実行したりできる Claude。日本語で頼めば作業してくれる |
| **Skill** | Claude Code が使う「手順書」。このメータには「環境を作る」「書き込む」「表示を変える」「更新する」の 4 つがある |
| **Git** | プログラムの変更の記録を管理する道具。ここでは作者のプログラムを手に入れる・更新するのに使う |
| **GitHub** | Git の記録をインターネットで公開する場所。このメータのプログラムは github.com/chaketek/circle_meter にある |
| **clone（クローン）** | GitHub にあるプログラム一式を、自分の PC にまるごとコピーすること |
| **git pull** | 作者の最新版をダウンロードして、手元のコピーに反映すること |
| **ビルド** | プログラム（人が読める文字）を、メータが実行できる形に変換すること |
| **書き込み** | ビルドしたものを USB でメータに送って入れること。「フラッシュ」とも言う |
| **PlatformIO** | ビルドと書き込みをする道具。初回に必要なものを自動でダウンロードする |
| **PowerShell** | Windows のコマンドを打つ画面。ビルドと書き込みはここで行う（Claude Code が代わりに打つ） |
| **COM ポート** | USB で繋いだメータが PC から見えるときの名前（`COM10` など） |
| **起動ログ** | メータが起動したときに USB で PC に送ってくる文字。書き込みが成功したか、設定が効いたかが分かる |
| **CAN** | 車の中の機器どうしがデータをやり取りする通信線（CAN_H / CAN_L の 2 本） |
| **通信速度（ビットレート）** | CAN の速さ。車の全部の機器で同じでなければならない。rusEFI の既定は 500 kbps |
| **ECU** | エンジンを制御するコンピュータ。ここでは rusEFI（uaEFI など） |
| **WBO** | ワイドバンド O2 センサのコントローラ。λ（空燃比）を測る。uaEFI は内蔵している |
| **λ（ラムダ）** | 空気と燃料の混ざり具合。1.00 がちょうど燃える比率（理論空燃比）。小さいと濃い、大きいと薄い |
| **AFR（空燃比）** | λ × 理論空燃比。ガソリンなら λ 1.00 = AFR 14.7 |
| **EGT（排気温度）** | 排気ガスの温度。高すぎるとエンジンを傷めるので、警告を出す |
| **終端抵抗** | CAN の両端に入れる 120 Ω の抵抗。両端の 2 本で、CAN_H–CAN_L 間が約 60 Ω になるのが正常 |
| **`user` フォルダ** | あなたの設定（`user_config.h`）とロゴを置く場所。作者の更新で上書きされない |
| **`user_config.h`** | あなたの設定ファイル。行頭の `// ` を消した行だけが使われる |
