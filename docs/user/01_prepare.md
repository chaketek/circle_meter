## メータの部品

| もの | 内容 | 備考 |
|---|---|---|
| 本体（どちらか） | **Waveshare ESP32-S3-Touch-LCD-2.1**（または 2.1B） | 丸い 2.1 インチ（480×480）。付属の 12 ピンのケーブルを使う |
| | **M5Stack Dial v1.1**（M5Dial） | 丸い 1.28 インチ（240×240）。横の Grove 端子（PORT.A）に繋ぐ。ボタンで AFR / λ を切り替えられる。**電源は本体の DC 入力（6–36 V）に車の 12V を入れる**（Mini CAN は M5Dial から 5V をもらう） |
| CAN ユニット | **M5Stack Unit Mini CAN** | 車の CAN の信号を本体に渡す。LCD-2.1 では車の 12V から本体用の 5V も作る |
| Grove ケーブル | Mini CAN に付属 | LCD-2.1: Mini CAN と本体の 12 ピンのケーブルを繋ぐ。M5Dial: Mini CAN と M5Dial を直接繋ぐ |
| USB ケーブル | **USB-C、データ通信できるもの** | 充電専用のケーブルでは書き込めません |

## 車の側

- **rusEFI の ECU**（uaEFI など）と、**rusEFI のワイドバンドコントローラ（WBO）**。uaEFI は WBO を内蔵しています。
- 排気温度も表示したい場合は、ECU で排気温度センサ（EGT）が設定済みであること。
- CAN の配線（CAN_H / CAN_L）にメータを繋げる場所。
- ECU の設定を見るための **TunerStudio**（[4. 書き込みと配線](04_flash_and_wire.md) で設定を確認します）。

## PC とアカウント

| もの | 内容 |
|---|---|
| Windows の PC | Windows 11 / 10。空き容量 **5 GB 以上**（書き込み用の道具を初回に自動でダウンロードします） |
| インターネット | 初回の準備と、更新のときに使います |
| **Claude のアカウント（有料プラン）** | Claude Code を使うのに必要です。どのプランで使えるかは Anthropic の案内（claude.com）で確認してください |
| GitHub のアカウント | **不要** です（プログラムは公開されているので、そのまま手に入ります） |

### LCD-2.1 と M5Dial の違い

| | LCD-2.1 | M5Dial |
|---|---|---|
| 画面 | 2.1 インチ・480×480 | 1.28 インチ・240×240 |
| 表示デザイン | 指針式 / リングを選べる | リングのみ |
| λ・排気温度・λ センサの状態 | あり | あり |
| 色・警告温度・ロゴの変更 | あり | あり（指針式の盤面の色は無し） |
| AFR / λ の切り替え | 設定ファイル | 設定ファイル、または本体のボタン |
| PC と繋ぐ口 | **UART と書かれた USB-C** | 本体の USB-C |
