# 7. 最新版に更新する

[← 6. ロゴを変える](06_logo.md) ｜ [目次](README.md) ｜ 次: [8. 困ったとき →](08_troubleshooting.md)

作者が不具合を直したり機能を足したりしたら、次のように頼むだけで取り込めます。

```text
最新版にして
```

Claude が次のことを行います。

| 順番 | 内容 |
|---|---|
| 1 | 手元のファイルが作者のものから変わっていないか確かめる |
| 2 | 作者の最新版をダウンロードして反映する（`git pull`） |
| 3 | 何が変わったかを短く説明する。設定に新しい項目が増えていれば紹介する |
| 4 | 本体に書き込んで、起動ログで確かめる |

- **`user` フォルダ（あなたの設定とロゴ）は、更新で消えたり上書きされたりしません。**
- 新しく増えた設定項目は、自動ではあなたの設定に足されません。使いたいときだけ「○○を使いたい」と頼んでください。
- 「すでに最新版です」と言われたら、何もする必要はありません。

## 作者のファイルを書き換えてしまっていた場合

`user` フォルダ以外のファイルを変えていると、Claude が「このままだと更新できません」と知らせます。
そのときは Claude の説明を読み、変更を一時的に **退避** してから更新するかどうかを決めてください。
退避した変更は消えずに残ります。
