## 1. ステークホルダ

| ID | ステークホルダ | 関心事 |
|---|---|---|
| SH-1 | ドライバ（兼オーナー、開発者） | 走行中に空燃比と排気温度を「読む」のではなく「見る」だけで把握したい |
| SH-2 | チューナー（自分自身 / TunerStudio 利用時） | セッティング中に細かな数値と過去の傾向が欲しい |
| SH-3 | 整備者 | 配線が単純で、故障時に切り分けやすいこと |
| SH-4 | 同乗者・第三者 | 視界の妨げにならない、まぶしくない |

## 2. 運用コンセプト (ConOps)

1. イグニッション ON → メータに 12V 供給 → オープニング画面（ロゴ）を表示。
2. rusEFI ECU が起動し CAN 送信開始 → メータが信号を捕捉 → ラムダページへ自動遷移。
3. 走行中はドライバがダイヤルに触れずとも常時ラムダを表示。周辺視野で色だけを認識できる。
4. 停車中・セッティング中はダイヤルを回してページを切り替え、詳細数値を確認する。
5. イグニッション OFF → 電源断（状態保存は不要、設定のみ不揮発）。

## 3. ステークホルダ要求

| ID | 要求 | 出所 | 優先度 | 上位 |
|---|---|---|---|---|
| `STK-01` | 走行中、視線をメータに固定せず**周辺視野**で空燃比の状態（濃い/適正/薄い）を判別できること | SH-1 | **Must** | ConOps 3 |
| `STK-02` | 空燃比は外周部のバーグラフで表現し、AEM ワイドバンドメータのように**値に応じて色が変化**すること | SH-1 | **Must** | STK-01 |
| `STK-03` | 排気温度を常時監視し、危険域に入ったことを明確に知らせること | SH-1 | **Must** | — |
| `STK-04` | 内周に数値表示を行い、**AFR 表示とラムダ表示を切り替え**られること | SH-2 | **Must** | — |
| `STK-05` | 表示の更新が滑らかで、値の変化に遅れを感じないこと | SH-1 | **Must** | STK-01 |
| `STK-06` | ラムダ・排気温度以外の情報（水温・回転数・油圧など）もページ切り替えで見られること | SH-2 | Should | ConOps 4 |
| `STK-07` | ページ切り替えは**ダイヤル（ロータリーエンコーダ）操作**で行えること。グローブ着用時でも操作できること | SH-1 | Should | STK-06 |
| `STK-08` | 起動時にオープニング画面（プライベータのロゴ）を表示すること | SH-1 | Should | ConOps 1 |
| `STK-09` | 配線はバッテリ電源（12V 系）と CAN 2 本のみで完結すること。追加の電圧変換器を要しないこと | SH-3 | **Must** | — |
| `STK-10` | ECU 未接続・CAN 途絶・センサ故障を**表示上で区別**でき、誤った値を本物のように見せないこと | SH-3 | **Must** | — |
| `STK-11` | 夜間走行で眩しくないこと。輝度を調整できること | SH-4 | Should | — |
| `STK-12` | ダッシュボード上の 1 DIN 相当スペース / メーターフード上に収まる丸形であること | SH-4 | **Must** | — |
| `STK-13` | 車両側 CAN バスに対して**書き込みを行わない**こと（ECU の動作に影響を与えない） | SH-3 | **Must** | — |
| `STK-14` | 設定（AFR/λ 表示、警告閾値、輝度）は電源を切っても保持されること | SH-2 | Should | — |
| `STK-15` | ファームウェアの更新が USB ケーブル 1 本で行えること | SH-3 | Should | — |
| `STK-16` | 将来、表示項目やページを追加できる構造であること | SH-2 | Could | — |

## 4. 制約条件

| ID | 制約 | 根拠 |
|---|---|---|
| `CST-01` | ハードウェアは **M5Stack Dial v1.1**（所有品）を使用する | 調達済み。変更不可 |
| `CST-02` | CAN 接続は **M5Stack CAN Unit（Grove 接続）**を使用する | 調達済み |
| `CST-03` | ECU は **rusEFI**。CAN は rusEFI の verbose broadcast を用いる | 車両既設 |
| `CST-04` | 表示器は制御に介入しない（受信専用） | STK-13 / 安全方針 |
| `CST-05` | 動作電源は車両の 12V 系（クランキング時 6V 程度まで降下しうる） | 車両仕様 |
| `CST-06` | 車室内温度は夏季 60°C 超に達しうるが、M5Dial の動作保証は 0–40°C | ハード制約（RSK として管理） |
| `CST-07` | 開発は PlatformIO + Arduino (ESP32) フレームワーク | DOC-40 |

## 5. スコープ外（Non-Goals）

- データロギング（SD カード記録）— v1.0 では実装しない
- Wi-Fi / Bluetooth によるスマホ連携 — 実装しない（電波法・消費電力・注意散漫の観点）
- ECU へのパラメータ書き込み（TunerStudio 代替）— **恒久的にスコープ外**（`CST-04`）
- 車検・保安基準適合のための純正メータ代替 — 追加メータとしてのみ使用する

## 6. 受入基準（ステークホルダ視点）

1. 実車アイドリング〜3000 rpm で、λ の変化が画面上で目視可能な遅れなく追従する。
2. 昼間の直射日光下で、運転席から外周バーの色が判別できる。
3. ECU の電源を落としたとき、数値が固まらず「信号なし」と明示される。
4. 1 時間の連続走行で再起動・フリーズが発生しない。
