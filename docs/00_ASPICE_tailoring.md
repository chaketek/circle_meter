## 1. 目的

本書は、個人開発規模の車載表示器プロジェクトに対して Automotive SPICE (ASPICE) PAM v3.1 / v4.0 のプロセス参照モデルを
**テーラリング（適用範囲の裁断）** した結果を定義する。

ASPICE をそのまま適用すると 1 名開発では成果物作成コストが開発コストを上回る。
一方で「要求 → アーキ → 実装 → 検証」のトレーサビリティは、**CAN 信号の誤解釈が走行中の誤表示に直結する**本件では実利がある。
よってトレーサビリティ骨格は残し、組織プロセス系・調達系は除外する。

## 2. プロジェクト特性（テーラリングの根拠）

| 特性 | 値 | テーラリングへの影響 |
|---|---|---|
| 開発体制 | 1 名 + AI エージェント (Claude Code) | ACQ / SPL / 組織プロセスを除外。レビューは PR チェックリスト + AI レビューで代替 |
| 生産形態 | 一品物（自家用・非量産） | SPL.2 (製品リリース) は「タグ + firmware.bin 添付」まで簡略化 |
| 安全性 | **表示専用。車両の制御・操作には一切介入しない** | ISO 26262 対象外 (QM 相当)。ただし *誤表示による運転者の誤判断* をハザードとして扱い、SYS.2 に「異常時は値を隠す」要求を置く |
| セキュリティ | CAN 受信専用（デフォルトで送信しない） | 車両バスへの書き込み経路を持たないことをアーキ制約として固定 |
| 法規 | 公道走行車両への追加メータ | 視界を妨げない設置、保安基準への適合は SYS.1 の制約として記録 |

## 5. 識別子（ID）体系

| 接頭辞 | 意味 | 生成元プロセス | 例 |
|---|---|---|---|
| `STK-nn` | ステークホルダ要求 | SYS.1 | `STK-01` ラムダを一目で読みたい |
| `SYS-nn` | システム要求 | SYS.2 | `SYS-12` 30 fps 以上で更新する |
| `SA-nn` | システムアーキ要素 | SYS.3 | `SA-03` CAN トランシーバ |
| `SWR-nn` | ソフトウェア要求 | SWE.1 | `SWR-21` λ→AFR 換算 |
| `SWA-nn` | ソフトウェアコンポーネント | SWE.2 | `SWA-02` CanRxTask |
| `SWD-nn` | 詳細設計ユニット | SWE.3 | `SWD-05` LambdaRingWidget |
| `UT-nn` | ユニットテスト | SWE.4 | `UT-03` 境界値 λ=0 |
| `IT-nn` | 結合テスト | SWE.5 | `IT-02` CAN 途絶検出 |
| `QT-nn` | 適格性確認テスト | SWE.6 / SYS.5 | `QT-01` 実車アイドル表示 |
| `RSK-nn` | リスク | MAN.5 | `RSK-02` 3 本目の終端抵抗 |

### 5.1 記述ルール

- 要求は 1 行 1 要求。`shall` 相当（「〜すること」）で書き、検証可能な数値を必ず含める。
- 各要求行は必ず **上位 ID** と **検証 ID** の列を持つ。これにより `DOC-50` は自動生成可能とする。
- 変更時は ID を再利用しない。廃止は `~~STK-07~~ (廃止: v0.3)` と取り消し線で残す。

### 5.2 トレーサビリティの連鎖

```
STK-*  ──►  SYS-*  ──►  SWR-*  ──►  SWA-* / SWD-*  ──►  実装ファイル
                │           │             │
                └──► QT-*   └──► IT-*     └──► UT-*
```

## 6. レビュー・承認の運用（1 名開発での代替手段）

ASPICE が要求する「独立したレビュー」は体制上成立しない。以下で代替する。

1. **CI ゲート** — `main` への直接 push 禁止。PR で単体テスト・ビルド・静的解析が通らなければマージ不可（`DOC-41`）。
2. **AI レビュー** — PR 作成時に Claude Code の `/code-review` を実行し、指摘を PR コメントに残す。
3. **セルフレビュー チェックリスト** — `.github/pull_request_template.md` の項目を全てチェックしたことをもって「レビュー済み」とする。
4. **実機ゲート** — 実車搭載前に必ずベンチ CAN 再生テスト (`QT-01`〜) を通す。
