## 5. 更新ルール

- 要求の追加・変更・廃止を行う PR は、**本表の更新を同一 PR に含める**（`DOC-41 §3.2`）。
- 本表で「上位 ID を持たない要求」「検証 ID を持たない要求」が発生した場合、
  それは仕様の漏れか、不要な要求である。どちらかを判断して解消する（`DOC-41 §5` D3）。
- 将来的に、コミットの `Refs:` 行と本表を突き合わせるスクリプト（`tools/check_trace.py`）を
  CI に追加することを検討する（現時点では手動）。
