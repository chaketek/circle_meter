# 表示デザイン A（指針式・大森風）の実機確認 2026-10-04

`SYS-21` / `SWR-49` / `SWR-50` / `DEC-10` の実装を、LCD-2.1 実機のデモモード（`lcd21_sim`）で確認した記録。

| 項目 | 値 |
|---|---|
| ボード | Waveshare ESP32-S3-Touch-LCD-2.1（`COM10`、UART 接続）+ UVC カメラ |
| env | `lcd21_sim`（`-O2`、LVGL 9.2.2、pioarduino 55.03.312-1） |
| 条件 | λ が 8.5 秒で 0.68 <-> 1.36 を往復、表示値に LPF（`SWR-24`）。**値が毎フレーム動く** |

## 性能（`SYS-12` / `QT-03` 暫定）

37 秒連続（AFR 表示 14 秒 -> λ 表示 14 秒）。

| 段階 | fps（最小 / 平均 / 最大） | 1 フレーム（描画 + flush） | 無効領域 |
|---|---|---|---|
| 最初の実装 | 28 / 33.1 / 38 | 平均 24 ms、最悪 33 ms | 平均 6k px |
| 文字盤の描画で重ならない要素を飛ばす（`DEC-10`） | **34 / 39.2 / 41**（λ 表示も 34 / 39.1 / 41） | **平均 15-17 ms**、最悪 21 ms | 平均 6-9k px |

描き直す画素は少ないのに遅かったのは、針の小さな矩形（1 フレーム 5-9 個）ごとに文字盤の約 40 要素
（目盛り 21 本・数字 6 個・円弧 6 本・三角・銘板 3 個）の描画指示を作り直していたため。
円環の要素は「描き直す矩形の中心からの最短・最長距離」、その他は外接矩形で重なりを判定し、重ならないものは指示を作らない。

## 目視確認（UVC カメラ）

| 確認 | 結果 |
|---|---|
| 文字盤（リム・色帯・目盛り・14.7 の三角・数字・銘板） | DOC-23 §3.5 どおり |
| 針（中心から浮かせた三角形） | 値に追従。Lost では消える設計（未確認: CAN 未接続のため途絶を作れない） |
| 主数値・EGT（B612 Mono、等幅） | `14. 4` ではなく `14.4`（小数点を 0.62 倍のセルに詰める）。桁は動かない |
| EGT 警告 / 危険 | 885 °C で黄、960 °C で赤の点滅とリムの赤 |
| AFR / λ 切替（`m`） | `1.058` も中央に収まる |
| デザイン切替（`v`） | リング版へ切り替わる（全面の描き直しで 1 フレーム約 80 ms。切替時のみ） |
| 針の通過跡 | 数往復スイープ後に両端で止めても、目盛り・数字・色帯に欠けや残像なし |
| オープニング | 新しいロゴ（縁のジャギーを直した版）が出る |

## 起動時間（`SYS-19` / `QT-06`）

`boot: first frame at 1266 ms`（アプリ開始から）をリセットから 1.7 秒で受信。**初回描画は約 1.7 秒**で、改訂後の `SYS-19`（2.0 秒以内）を満たす。
オープニングは当初 3,136 ms で、フェードを「16 ms x 回数」で回していたため各回の処理時間が積もっていた。経過時間と開始時刻からの締め切りで区切るように直し、**3,001 ms**（3 回とも同じ）になった。`SYS-18` は 2026-10-04 に「3.0 秒（許容 ±100 ms）」へ改訂した。
