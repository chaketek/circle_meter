# LVGL 化の測定記録 2026-10-02（フェーズ P4 着手）

λ ページ・スプラッシュ・シミュレータデモを LVGL 9.2.2 で実装し、`OPN-12`（480×480 RGB パネルの実描画性能）の
LVGL 構成での値を取った記録。CAN は未接続（`lcd21_sim`: λ と EGT をスイープ）。

| 項目 | 値 |
|---|---|
| ボード | Waveshare ESP32-S3-Touch-LCD-2.1（`COM10`、UART 接続） |
| env | `lcd21_sim`（`-O2`） |
| platform | pioarduino 55.03.312-1（Arduino-ESP32 3.3.12 / IDF 5.5.5） |
| LVGL | 9.2.2（9.6.0 と比較: `DEC-09`） |
| 表示ライブラリ | ESP32_Display_Panel v1.0.4 |
| 条件 | **値が毎フレーム動く最悪条件**: λ は 8.5 秒で 0.68 <-> 1.36 を往復し、表示値に LPF（λ 80 ms / EGT 200 ms、`SWR-24`）を掛ける。EGT は 5 °C 刻み |
| 確認方法 | シリアルの計測値（fps・描画時間・画素数）と、UVC カメラの画像 |

## 結果（最終構成）

37 秒連続（AFR 表示 14 秒 -> λ 表示 14 秒、スイープ全域と DANGER 域を含む）:

| 表示 | fps（最小 / 平均 / 最大） | 1 フレームの描画 + flush | 1 フレームの無効領域 | 最悪の 1 秒平均 |
|---|---|---|---|---|
| AFR | 36 / **39.2** / 41 | 平均 9.0 ms（描画 8.0 + flush 1.0） | 平均 9.8k px | 13.1 ms |
| λ | 35 / **39.2** / 40 | 平均 12.0 ms（描画 10.5 + flush 1.5） | 平均 14.0k px | 16.4 ms |

`SYS-12`（30 fps 以上）を **λ ページで満たした**（更新周期 40 Hz。33 ms の予算に対し 1 フレーム平均 9-12 ms）。
値を止めると描画量はほぼ 0（診断文字の更新 1 回/秒のみ）。

| メモリ | 値 |
|---|---|
| 内蔵 SRAM の空き（UI 起動後） | **169 KB**（`SYS-62` の 150 KB 以上を満たす）。静的使用 149.8 KB（45.7%） |
| PSRAM の空き | 7,737 KB（フレームバッファ 450 KB を含めた残り） |
| LVGL ヒープ | 使用 9%（最大 5-6 KB / 64 KB）。過大なので、ページを増やしたあとに見直す |
| Flash | 1.03 MB（15.8%）。うちフォント 3 書体 75 KB、ロゴ 127 KB |

## 性能改善の経緯（λ 表示、1 フレームあたり）

| 段階 | 変更 | fps | 描画 + flush | 無効領域 | 判明したこと |
|---|---|---|---|---|---|
| 0 | 最初の実装（`lv_label`、`-Os`、信号 20 Hz） | 20 | 29 ms | 70k px | 信号が 20 Hz でしか変わらないため 20 fps は**データ周期**。描画の上限ではなかった |
| 1 | `-O2` | 20 | 24 ms | 63k px | 描画 -20% |
| 2 | LPF で毎フレーム値を動かす（`SWR-24`） | 27-30 | 27-30 ms | 62-73k px | **これが `SYS-12` の最悪条件**。余裕がない |
| 3 | LVGL 9.6.0 | 24-30 | 同等 | 同等 | 差は ±5%。`DEC-09` で 9.2.2 固定 |
| 4 | `BigNumber`（自前・桁単位の無効化。`DEC-08`） | 28-29 | **12 ms** | 14k px | `lv_label` は描画範囲を 1.7 倍に広げ、全桁を再描画していた |
| 5 | 更新周期を固定（`+= 周期`） | 29.4 | 13 ms | 14k px | `now + 33` では待ちの丸めで 28 fps になる |
| 6 | リングの無効化を 15° 分割 + 更新 40 Hz | **39.2** | **12 ms** | 14k px | ゾーン境界で全画面（23 万 px、78 ms）を描き直していたのを環状部だけにした。最小 fps が 26 -> 35 |

## 目視確認（UVC カメラ）

| 確認 | 結果 |
|---|---|
| スプラッシュ（ロゴ・版数） | 表示される。ロゴは黒地に白抜き + 赤のスクリプト（`make_logo.py` の輝度反転どおり） |
| 各ゾーンの色・先端マーカー・目盛 | 緑（AFR 14.4）/ 赤（16.7, 20.0）で正しい。先端の白線あり |
| AFR / λ の切替 | `AFR 16.7` / `LAMBDA 1.209` とも円に収まる |
| EGT の `°C` | 正しく出る（`740°C`, `815°C`, `960°C`）。**初回は「°」が抜けていた**（`BigNumber` がバイト単位で、UTF-8 の 2 バイト文字を壊していた。コードポイント単位に修正） |
| EGT `DANGER` の点滅 | 連写 20 枚で 2 Hz（点灯 5 コマ / 消灯 5 コマ）。**消灯フレームで警告帯が完全に消える**（描き残しなし） |
| 動いている数字の残像・矩形ムラ | 走行中は新旧の桁が重なって写るが、**停止状態では出ない**。描画不良ではなくカメラの露光との重なり |

## 未解決・要確認

| 項目 | 内容 |
|---|---|
| `SYS-19` 初回描画 | 当初の 1.0 秒は未達（リセットから約 1.6 秒。`Board::begin()` が約 1.1 秒）。**実力値を反映して 2.0 秒以内に改訂した**（2026-10-02）。正確な値は `boot: first frame` ログで `QT-06` として測る |
| `RSK-14` / `IT-16` | LVGL 構成での NVS 書き込み・CAN 受信中の表示の乱れは**未確認**（NVS は未実装、CAN は未接続） |
| 警告帯の点滅 | 1 回の切替が約 50 ms。2 Hz 点滅（秒 4 回）なので、`DANGER` 中は 1 秒あたり約 8 フレーム分が重くなる（それでも最小 35 fps） |
| EGT の桁数 | 4 桁（1000 °C 以上）は円からはみ出す。想定外として許容（`DOC-23 §3.4`） |
| 色 | カメラは白を水色に写す（R 162 / G 245 / B 250）。ファームの色順の誤りではない（青が赤に出るはず）。実物の色は目で確認すること |
| CAN | `lcd21` 環境（実 CAN）は IDF 5.5.5 の TWAI レガシードライバごとビルド・リンクできる。**実機動作は未確認**（`OPN-13`） |
| タッチ | `DisplayHal::readTouch()` は実装済みだが、`InputDriver`（`SWD-06`）が無く UI には繋いでいない |
