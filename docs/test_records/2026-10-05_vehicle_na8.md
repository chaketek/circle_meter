# 車両接続記録 2026-10-05（作者の NA8 / LCD-2.1 / 実 CAN 版）

作者の車両（NA8。rusEFI WBO と MoTeC を同一 CAN バスに載せた構成）にメータを繋ぎ、受信を確かめた記録
（`OPN-19` / `OPN-03` / `IT-10` の前段）。エンジン停止・キー ON の状態。

| 項目 | 値 |
|---|---|
| FW | `lcd21` -> `lcd21_1m`（`feat/dial-variant-a`、表示デザイン A） |
| 接続 | Mini CAN Unit を車両の CAN バスへ。本体側ケーブル: 黄 CAN TX / 緑 CAN RX / 赤 5V / 黒 GND |
| 観測 | 同じバスに PCAN-USB を **listen-only**（`BusState.PASSIVE`）で繋ぐ。PC からは何も送信していない |

## 1. 症状: 何も受信できない

`lcd21`（500 kbps）のメータのシリアルは `rx=0`、**`rec=128`**（受信エラーで error passive）、`sensor=NO_SIGNAL`。

PCAN でビットレートを変えて 3 秒ずつ観測した:

| ビットレート | 正常フレーム | エラーフレーム |
|---|---|---|
| 500 kbps | 61 | 7,647 |
| 250 kbps | 0 | 3,424 |
| **1 Mbps** | **3,381**（`0x190`–`0x193` を含む） | 3,373 |
| 125 kbps | 0 | 1,904 |

**車両のバスは 1 Mbps**（MoTeC 併用のため。ユーザー確認）。メータは 500 kbps で受けていたので何も受信できなかった。
1 Mbps でも残っていたエラーフレームは、500 kbps のメータがバス上で出していたものとみられる（メータを 1 Mbps に
したあとは 6 秒で 84 件に減った）。

## 2. 対処

`SYS-01` は 250 / 500 / 1000 kbps の設定を求めているが、設定メニューと NVS（`SWR-65`）が未実装で、既定の 500 kbps に
固定されていた。ビルドフラグ `CM_CAN_BITRATE_KBPS` を追加し、1 Mbps の環境 `lcd21_1m` を作った。
**`lcd21` は既定の 500 kbps のまま**（送付先の車両は uaEFI 単独で 500 kbps）。

## 3. 1 Mbps での結果

PCAN（listen-only、6 秒）で見たバス上のフレーム:

| ID | 周期 | 例 | 内容 |
|---|---|---|---|
| `0x190` | 100 f/s | `a0 01 20 4e 0c 03 00 00` | WBO 0 StandardData: Version `0xA0`、Valid 1、λ 2.000（大気）、779 °C |
| `0x191` | 100 f/s | `2b 01 c2 01 37 02 7c 00` | WBO 0 DiagData: Status 2（RunningClosedLoop） |
| `0x192` / `0x193` | 各 100 f/s | | WBO 1（2 チャンネル目）。本機は使わない |
| `0x0F0` `0x0F3` `0x3E8`–`0x3ED` `0x460` `0x461` ほか | | | rusEFI の verbose broadcast ではない（MoTeC など他の機器とみられる。中身は未調査） |
| `0x200`–`0x20F` | **無し** | | rusEFI の verbose broadcast が出ていない -> **EGT は表示できない**（`OPN-03`） |

メータ（`lcd21_1m`）のシリアル:

```
rx=2768 f/s=200 unk=2768 dlc=0 ovf=0 tec=0 rec=0 | lam=2.000 egt=(none)0 | ageL=0 ... | sensor=OK -1
```

- `rx` 200 f/s = `0x190` + `0x191`。`unk` は `0x192` / `0x193`（フィルタは `0x190`–`0x19F` を通すが、デコードはインデックス 0 だけ）
- `tec=0`、`rec` 0〜5。λ = 2.000、センサ状態 OK
- 表示はユーザーが実車で目視し、想定どおりの動作を確認した（カメラ未接続のため撮影はしていない）

## 4. 残り

- 送付先の車両（uaEFI 単独、500 kbps）で `lcd21` が受信できること（`OPN-19`）
- 作者の車両の EGT: rusEFI の verbose broadcast を有効にするか、EGT を他の発信元から取るか（`OPN-03`）
- エンジン始動後の表示（`IT-10` / `QT-01`）
