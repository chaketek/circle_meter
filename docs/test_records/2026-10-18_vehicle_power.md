# 車両での電源の確認 2026-10-18（OPN-14 / OPN-20）

作者の車両（NA8）で、Mini CAN Unit が車両の 12V から作る 5V を Grove で本体へ入れて、両機種が動くかを確かめた（ユーザーによる実施・報告）。

| 機種 | 電源の経路 | 結果 |
|---|---|---|
| LCD-2.1 | 車両 12V -> Mini CAN の端子台 -> Grove 5V（赤）-> 12PIN の `VBus`。USB は繋がない | **動作**。起動・表示・CAN 受信とも問題なし（`OPN-14` 成立） |
| M5Dial | 車両 12V -> Mini CAN の端子台 -> Grove 5V（赤）-> PORT.A の 5V | **動作しない**。画面が点かず、まったく動かない（`OPN-20` 不成立） |

## 判断

- **LCD-2.1 は Mini CAN の 5V で動かす構成のままとする。** 消費電流とクランキング時の挙動は未測定。
- **M5Dial は本体の DC 入力（6–36 V）に車両の 12V を入れる方式に改める**（ユーザー判断。DOC-12 §8.5）。
  PORT.A の 5V は M5Dial が外へ出すための端子で、本体へ電源を入れる経路になっていないとみられる（回路図での確認はしていない）。
- M5Dial を DC 入力で動かすときの Mini CAN の電源と Grove の赤（5V）の扱いは `OPN-21` として残した。
  推奨は「赤を繋がず、Mini CAN も端子台の 12V で動かす」（5V の電源どうしを直結しない）。車両で確かめるまで、利用者ガイドは「確認中」とする。
