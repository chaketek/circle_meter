# 書き込む（配布先ユーザー向け）

手順書は `docs/user/04_flash_and_wire.md`。相手は Git も Claude Code もほとんど使ったことがない人。

## 守ること

- 専門用語は一言で言い換える。1 回に頼む操作は 1 つ。
- **ビルドと書き込みは PowerShell で実行する**（Git Bash では失敗する）。
- **本体が USB で PC に繋がっているときだけ書き込む**。繋がっていなければ繋いでもらう。
- 書き換えてよいのは `user/` フォルダだけ。PC から CAN へ何かを送る操作はしない。

## 手順

### 1. 機種と、どちらを書き込むかを決める

会話から分からなければ尋ねる。機種は、繋がっている COM ポートの VID でも分かる（1A86 = LCD-2.1、303A = M5Dial。`python -m platformio device list`）。

| 選択 | 内容 | LCD-2.1（PowerShell） | M5Dial（PowerShell） |
|---|---|---|---|
| **デモ** | CAN を繋がずに、針（リング）と数字が自動で動く。画面と設定の確認用 | `./tools/flash.ps1 -Sim` | `./tools/flash.ps1 -Board m5dial -Sim` |
| **車両用** | 車の CAN から λ と排気温度を受けて表示する | `./tools/flash.ps1` | `./tools/flash.ps1 -Board m5dial` |

車両用のときは **CAN の通信速度**を確かめる。

- rusEFI（uaEFI など）だけの車は、ほとんどが **500 kbps**（rusEFI の既定）。何もしなくてよい。
- 他の機器（MoTeC など）と同じ CAN にいて **1 Mbps** にしている車は、`user/user_config.h` に
  `#define USER_CAN_BITRATE_KBPS 1000` が必要（行頭の `// ` を消す）。分からなければ 500 で書き込み、
  手順 3 の判定で「通信速度が合っていない」と出たら 1000 にして書き込み直す。

### 2. 書き込む

`user/user_config.h` が無ければ `user/user_config.example.h` からコピーしてから実行する（`setup-meter` の手順 3）。

```powershell
./tools/flash.ps1 -Sim
```

ポートは自動で探す（LCD-2.1 は CH343、M5Dial は VID 303A）。ビルドで止まったら:

- `static assertion failed: USER_... は ... で指定してください` → `user/user_config.h` の値が範囲外。
  メッセージをそのまま日本語で伝え、どの行をどう直すか提案する（勝手に直さず、確認してから直す）。
- `本体の COM ポートが見つかりません` → ケーブルと挿す口（LCD-2.1 は UART 側）を確かめてもらう。
- 書き込み中に `Failed to connect` → LCD-2.1 は本体の **BOOT ボタンを押したまま RESET を押して離し**、BOOT を離してから、もう一度実行する。M5Dial は USB を挿し直して再実行。直らなければ推測で手順を作らず、M5Stack の公式ドキュメント（ダウンロードモード）を案内する。

### 3. 確かめる

```powershell
python tools/meter_log.py
```

車両用で車に繋いでいるときは `--seconds 20` を付ける（キー ON にしてもらってから）。M5Dial は再起動せず、`i` を送って起動ログを出し直させて読む（自動）。

出力の `OK` / `NG` をそのまま見せ、`NG` は次のように説明する。

| 出力 | 意味と次の一歩 |
|---|---|
| `範囲外のため既定値のままの項目` | `user_config.h` の組み合わせがおかしい（例: λ の色の境目の順番）。項目名を示して直し方を提案 |
| `CAN を受信できていません（受信エラー rec=...）` | 通信速度が車と合っていない。500 と 1000 を入れ替えて書き込み直す |
| `CAN のフレームが届いていません` | 配線・キー ON・ECU 側の設定（`docs/user/04_flash_and_wire.md` の「ECU の設定」）を順に確かめる |
| `起動メッセージが読めませんでした` | 書き込みに失敗したか、ケーブルが抜けた。手順 2 からやり直す |

画面の見た目はユーザーに見てもらう（「針と数字が動いていますか？」のように 1 つずつ聞く）。
カメラがあっても、配布先では使わない前提で進める。

### 4. 終わったら

書き込んだ種類（デモ / 車両用・通信速度）と、反映されたユーザー設定を 1〜2 行で伝える。
